## 尚未达到原版一致的部分

1. **主线调度仍是 67 个网页节点。** 还没有完整替换为原版所有进入、时间、坐标触发器。已修正具体错序及三道漏掉的盘查，但不能据此宣称所有分支一致。
2. **事件解释器仍不完整。** 摄像机/控制角色、复制角色、布局与原组动画结尾状态并非全部对应；音效/音乐指令和暂停提示未全部接入。原 Java 平台的联网、退出、SMS/计费指令没有照搬到浏览器。
3. **战斗仍有回合适配。** 玩家逐人下令后敌方结算，尚未还原原版全部行动条、反击、仇恨选人、异常自然恢复与持续增益过期时机。混乱仍采用简化误伤逻辑；技能中未被现有命令适配的特殊效果需继续核对。普通失败仍提供休整重试，而非原版 Game Over。
4. **原版能力扩展待适配。** 原表杀气上限为 100；原 Java 有扩至 300 的付费入口。网页没有伪装完成付费解锁，耗 200 杀气的绝技仍需后续明确映射该扩展功能。妙手空空等同样没有复刻 SMS 支付。
5. **出口图只提取直接跳转。** 条件分支/选择中的部分跳转由解释器处理，但未全部进入跨地图引路图。图中没有路线时，网页仍有直接切换目标地图的兼容逻辑。
6. **旧物品别名和剧情赠物兼容逻辑尚在。** 旧版存档使用的 steel、wood 等 ID 尚未全部迁移为原始 ArmData ID；主线赠物、支线数量与失去物品的对应需继续逐段核对。
7. **缺少六章从头到尾的实际通关验收。** 自动测试与若干事件浏览器检查不能替代全路线通关，也不能证明所有宝箱、人物、奖励和转场没有遗漏。
