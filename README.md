# 满江红二 · 铁骑红颜：触屏网页版

手机和电脑浏览器可玩。点地面寻路、点人物交谈、点选招式后确认施放。地图与人物使用现有 AI 重绘素材，剧情、地图碰撞、属性和技能读取 Java 原作数据；部分战斗角色仍使用原版合成图。

[在线试玩](https://malqqin.github.io/manjianghong-web/) · [GitHub 源码](https://github.com/malqqin/manjianghong-web)

最新核对：[六项反馈与原版差异](docs/review-20261118.md)。当前版本仍是网页重建，尚未完整运行原版全部事件和战斗引擎。

## 启动与发布

需要 Node.js 18 或以上版本。双击 **启动游戏.cmd**，或运行 `npm start`，打开 **http://localhost:4173**。无需安装 npm 依赖。

手机连接电脑的同一个 Wi-Fi，输入启动窗口显示的 WLAN 地址。电脑需保持服务器运行；网络变化后以启动窗口的地址为准。

`npm test` 运行逻辑测试；`npm run build` 生成 `dist/`，只复制发布清单中的运行资源。推送 main 后 GitHub Actions 测试、构建并发布 GitHub Pages。HTTPS 或 localhost 支持 Service Worker 缓存；局域网 HTTP 通常不提供离线安装功能。

## 操作

- **地图显示**：电脑恢复原来的限宽布局、页头、侧栏和底栏，探索地图使用原来的缩放，剧情按原来的 240×320 比例适配。手机竖屏、横屏和触屏平板继续铺满可用视口。顶部不再提供「全屏」按钮。
- 点地面自动绕障碍行走；点人物、宝箱，走近后互动。同行队员沿路径跟随。
- 小型任务签「引路」前往当前主线目标。拖动地图查看周围，双击回到身边；「行路图」查看已到过的地方和主线目的地。
- 对话逐字显示：轻点显示本页全文，再点翻页。**没有整段跳过剧情按钮**。「江湖记」可回看已完成节点。
- 剧情读取人物走位、转身、显隐、居中旁白、竖排诗句、黑屏亮场、雨雪、头像切入和闪屏。原脚本主动黑屏仍保留，取消自动添加的上下黑边。
- 接触原版旋风进入战斗。可刷新旋风离场后，累计约 **16 秒地图活动时间**再出现；战斗、对话、菜单和后台标签页暂停计时。不可刷新旋风保持清除，御剑可避战。
- 战斗敌人在左、我方在右。点我方人物或小头像切换操作者，点敌人选目标，再选攻击、技能、道具、防御或商店。
- 点选技能、药品先看说明，再确认；取消不会消耗物品或行动。治疗、用药可选择我方目标。每人有独立生命、精气、倒地和复活状态。
- **普通药占用操作者行动，部分特级药保留行动**，依原版道具标志执行。药品面板显示说明。特级药用后仍选中原人物，可继续施法。
- 我方未行动人物等待下令，本轮存活人物全部行动后敌方结算。原规则战斗的普攻、防御不额外回精气；可使用返气丸等药品。
- 「行囊」使用缩略图格子，按装备、药品、秘籍、信物分类；点格子查看真实属性、数量、装备者和等级要求，再佩戴、卸下、使用或研习。部分物品共用同类缩略图。
- 「同伴」查看属性与武学；商店从对应场景 NPC 进入，读取原货品与价格。行囊不提供任意升级、休息入口。
- 「御剑」切换全队飞行；落地回到可通行地面。设置可切换声音、步速、减少动态，并导入、导出存档。
- 电脑支持方向键/WASD、空格/Enter、G 引路、J 江湖记、Esc 关闭面板。

## 剧情和原版一致性

六章顺序为：年少轻狂祸乱起、欢喜冤家两落魄、情窦初开汴京城、壮志飞过紫云山、儿女泪洒衣冠冢、金戈铁马战襄阳。已串联 67 个网页主线节点，含 1,877 条对白、旁白及战后文字；逐句来源保存在 `assets/original-story.json`。

原数据清点包括 43 个场景、1,197 条角色记录、292 条事件程序、330 个初始可见旋风和 62 个直接出口；属性表有 85 件装备、74 件道具、69 种怪物、78 支敌队、69 条技能。这些是数据覆盖数，不等于每条事件都已完整移植。

已接入原初始行囊、人物成长、装备条件、秘籍研习、药品作用、商店、敌队及掉落，并按原表计算技能伤害、目标数、异常和施法动画。敌方技能同样播放施法姿态及目标光效，包含技能自疗和减伤变化。普通药和特级药的行动差别来自原版 `o.java`。

仍有实质差异：主线未全面换成原坐标/时间触发器；事件解释器、行动资格、反击、仇恨及部分持续效果仍有简化；普通失败仍可休整重试；200 杀气绝技所需的原付费扩展尚未适配；引路图、旧物品兼容和剧情赠物仍需继续核对。没有完成六章从头到尾的人工通关，不能称作完全还原。详细范围见 [核对记录](docs/review-20261118.md) 和 [此前的规则审查](docs/original-parity.md)。

## 存档

存档保存在当前浏览器。不同浏览器、不同访问地址互不同步；设置支持 JSON 导入/导出。对话刷新从已读位置继续，战斗刷新从战前检查点恢复，战斗结果点确认后推进。

旧四幕存档先备份，再转入原作六章主线并带入银两、药品；六章存档保持节点。规则升级保留旧存档备份，旧道具别名仍有兼容逻辑。旋风旧墙钟记录一次性迁移为地图活动时间。

## 画面和来源

42 张地图及现有行走、头像、界面等素材已重绘，原版的逻辑坐标、碰撞及动画数据继续使用。本轮从已有 AI 母图恢复 11 套战斗重绘及 1 套衍生图，修复重打包覆盖 AI 图的问题；另有 10 套新增战斗角色仍使用原版部件合成。分类来源见 `assets/battle-art.json`；本轮没有重新调用生图服务。

地图和角色按比例绘制；原版战斗合成动画和部分光效仍取自原始数据。行囊是新的触屏格子界面，部分装备、药品共用类别图；不是每件物品都有独立插画。具体来源、生成记录和适配差异见 [素材来源](素材来源.md)。

## 主要文件和验证

- `game.js`：探索、面板、剧情调度与战斗表现；`bag.js`：格子行囊。
- `core.js`、`journey.js`：存档、主线与战斗配置；`character-rules.js`、`combat-rules.js`、`items.js`、`inventory.js`、`progression.js`：原版规则适配。
- `exploration.js`、`original-field.js`、`field-motion.js`：原场景对象、事件与旋风；`locomotion.js`：寻路、跟随与地图镜头。
- `tactical.js`、`presentation.js`、`native-effects.js`：逐人结算、动画、原版合成光效。
- `story-player.js`、`story-presentation.js`：原作轨道、对白和诗句；`assets/native-story.json` 保存场景与演出数据。
- `polish.css` 及其他 CSS：电脑、手机、横屏界面；`sw.js`、`precache.json`：离线缓存，当前版本 `mjh-native-36`。
- `scripts/restore-ai-battle-art.py`：从已有母图恢复战斗帧；`scripts/build-site.mjs`：发布资源检查。
- `assets/fonts/`：本地霞鹜文楷轻便版及 OFL 许可。
