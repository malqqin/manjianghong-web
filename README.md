# 满江红二 · 铁骑红颜：触屏网页版(最好手机端玩，体验更好)

手机和电脑浏览器可玩，无虚拟方向键。点地面寻路、点人物交谈、点选招式后确认施放。本版使用原始像素素材，停用四倍超分图；对白、走位、竖排诗句及黑屏等剧情演出读取 Java 原作数据。

## 在线试玩

[打开网页版](https://malqqin.github.io/manjianghong-web/) · [GitHub 源码](https://github.com/malqqin/manjianghong-web)

手机可直接打开 HTTPS 地址；存档保存在当前浏览器。电脑本地存档可在设置中导出，再在网页版导入。

推送 main 分支后，GitHub Actions 会运行测试、构建并发布到 GitHub Pages。`npm run build` 生成 `dist/`，仅包含运行资源，不部署测试、文档或历史增强图片。

## 启动

需要 Node.js 18 或以上版本。在此目录双击 **启动游戏.cmd**，或运行 `npm start`，打开 **http://localhost:4173**。无需安装 npm 依赖。

手机连接电脑的同一个 Wi-Fi，输入启动窗口显示的 WLAN 地址，例如 **http://10.10.100.153:4173**。电脑需保持服务器运行；网络变化后以启动窗口的地址为准。

也可将网页、脚本、CSS、manifest、precache.json、sw.js 和 assets 上传至静态网站托管。HTTPS 或 localhost 支持 Service Worker 缓存；局域网 HTTP 通常不提供离线安装功能。

## 操作

- 点地面自动绕障碍行走；点人物、宝箱，走近后互动。
- 点任务卡「引路」前往当前主线目标，跨场景时自动衔接。
- 拖动地图查看周围；双击回到身边。「行路图」可前往已经到过的地方和当前主线目的地。
- 对话使用原版底部米黄边框，头像伸出上沿，两行分页。文字逐字显示；轻点显示本页全文，再点翻页。「略过剧情」结束当前段。剧情可从「江湖记」中点已完成节点回看。
- 原作剧情轨道包含人物走位、转身、上下黑边、居中旁白、竖排诗句、黑屏亮场、雨雪、头像切入和刀光闪屏。诗句从右向左逐字出现，轻点显示全文，再点继续；黑屏按脚本指令触发。
- 同行队员沿实际行走路线连续跟随，转弯、停步和步伐分别计算。新地图完整载入后直接切换，取消进场中央标题效果。
- 接触地图上的原版旋风进入战斗，击退后旋风消失；御剑时可以避开。
- 战斗敌人在左、我方在右。点我方人物或下方小头像，头顶原版箭头指明当前人物；点敌人选目标，再选攻击、技能、防御或药品。三人均为手动操作。
- 战斗栏参考原版 battle.bin：攻击、技能、道具、防御、商店五个原版图标，下方为三人小头像和红色生命、青色精气条。战斗时收起网页页头、侧栏与导航，场景占满可用区域。
- 技能、道具为米黄窗框的双列菜单，点选红字选项先看说明和精气消耗，再点「施放／使用」。精气不足仍可查看说明，确认按钮会禁用。治疗和金疮药使用后再选择我方目标；清平丸作用于当前人物。取消菜单不会消耗回合。
- 每条指令只由所选人物执行，结束后等待下一名队员下令；本轮存活队员全部行动后，敌方逐一反击。队员有独立生命、精气、倒地和复活，治疗与用药可选择我方目标。怪物倒下并消散后显示奖励。
- 普攻回气，防御降低伤害并回气；还可用药、解除异常和购买战斗补给。行囊「歇脚调息」恢复全队。
- 「同伴」「行囊」「江湖记」查看角色、佩戴装备、购买物品、研习枪法和回顾剧情。
- 「御剑」切换全队飞行，三人各自脚踩剑、保留自己的造型与方向；落地时回到可通行地面并恢复步行姿态。
- 电脑支持方向键/WASD、空格/Enter、G 引路、J 江湖记、Esc 关闭面板。

## 剧情和功能范围

新旅程按原作六章顺序推进：年少轻狂祸乱起、欢喜冤家两落魄、情窦初开汴京城、壮志飞过紫云山、儿女泪洒衣冠冢、金戈铁马战襄阳。

已串联 67 个主线节点和 1,877 条对白、旁白（含战后文字），包含凤凰山逃亡、汴京、紫云山、衣冠冢、襄阳及「花与莲」终章。保留沥泉枪、蛇毒、雪莲与遗忘所爱的结局设定。支持武器/戒指/玉佩、两位同伴同时参战、枪法成长、冰冻/灼烧/混乱、战斗补给，以及汴京字画和地窖两项支线。

本次修正了兵营二、兵营三及战场上额外插入的必打关，补回金兀术与兰芷萱的过场、凤凰山战后对白；人物称呼随原文揭示。逐句来源的场景、分组和字符串编号记录于 `assets/original-story.json`。

「长虹贯日」「燎原四方」「碧月飞星」「暗香疏影」「如沐春风」等名称与一级说明取自原版 `SkillData.bin`，核对记录见 `assets/skills-source.json`。技能有实际伤害、治疗、增益或异常效果。一级精气消耗、施法者/目标的动画编号按原记录恢复，完整解析见 assets/combat-skills-source.json。战斗使用 currency.bin/currency.png 的合成帧，按原版 80ms 时钟播放，包含部分全屏粒子层；不再使用地图光效代替技能。

这是基于原作文字及地图数据重建的网页版本，尚未执行 Java 原版的完整事件脚本，不能称作剧情和功能的完整移植。路线触发、战斗公式及触屏交互由网页引擎实现；全部隐藏事件、全部道具和原引擎行为尚未逐项移植。当前采用我方逐人下令、随后敌方行动的回合编排，尚未移植原版速度/行动资格算法；伤害平衡、技能解锁成长及全屏粒子位置仍有差异，不能称作战斗完整等同原引擎。

## 旧存档与进度

检测到旧四幕改编篇的存档后，会先备份旧档，再从凤凰山原作主线启程，并带入银两与药品。已在六章主线内的存档保持当前节点；各节点编号未变。

进度保存到当前浏览器。对话中途刷新会从已读位置继续；战斗中刷新从战斗前检查点恢复。战斗结果必须点「继续前行」确认后再推进目标。

设置提供 JSON 导入/导出。不同浏览器、不同访问地址的存档独立，不会自动同步。

## 画面与素材

42 张地图、头像、装备、战斗图及光效改用原始尺寸 PNG，不再对源文件做超分或平滑处理。浏览器按屏幕大小以像素方式显示，清晰度受原始像素数量限制。

人物方向逐角色核对：向上走显示背影，向下走显示正面，左右使用各自侧面。金兵原图的待机和行走顺序与主角不同，已单独映射。

原始 PNG 保留不变，运行素材位于 assets/native/，剧情演员直接读取原始合成帧。旧 assets/enhanced/ 图片保留作历史备份，运行时不再选用。三人御剑中主角使用原版帧，两名同伴由自己的原始站姿与原版剑合成；详见 **素材来源.md**。

## 文件和验证

- `game.js`：触控探索、剧情播放、战斗表现和面板。
- `core.js`：寻路、结算、存档校验；`journey.js`：原作主线、装备及战斗配置；`skills.js`：角色招式；`encounters.js`：旋风接触遇敌。
- `presentation.js`：四向图集映射、动画与命中状态；`tactical.js`：逐人战斗结算；`native-effects.js`：原版战斗合成帧。
- `locomotion.js`：连续路径跟随、跨格步行、地图就绪切换及镜头定位。
- `assets/fonts/`：霞鹜文楷轻便版的游戏文字子集及 OFL 许可，本地加载。
- `assets/original-story.json`：原作对白与主线顺序；`assets/maps.json`：原版地图碰撞数据。
- `assets/native/`：原始尺寸素材与三人御剑图集；`story-player.js`、`story-presentation.js`：原作演出；`assets/native-story.json`：43 个场景与 49 套精灵数据。
- `style.css`、`hd.css`、`native.css`、`native-ui.css`：响应式界面、原版对白与战斗菜单样式；`assets/native-ui-source.json`：原版界面坐标和四张 UI 图的 SHA-256。
- `server.mjs`：本地静态服务器；`sw.js`、`precache.json`：离线缓存。

运行 `npm test` 验证主线终止、路径可达、装备效果、存档、异常状态、战斗可完成、四向动画、逐次命中与退场顺序。实际浏览器验证范围见 **验证记录.md**。
